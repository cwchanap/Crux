## Global constraints

- Target Python **3.11**, `tensorflow-cpu==2.15.1`; record the exact interpreter build after successful provisioning. Do not change notebook Python or Crux's Python 3.12 project environment.
- Preserve `runtime/oaf_tf1/`, `src/`, original checkpoint bytes, emitted-frame instrumentation and oracle; perform adaptations only in an experimental scratch copy.
- Source compatibility reference: Magenta `c15687ebd1c1cc12658cd468c737d3c24c02b918`. Selective source reuse with licenses, no wholesale Magenta install or neural-network rewrite.
- Set `CUDA_VISIBLE_DEVICES=-1`, `PYTHONHASHSEED=0`, `TF_ENABLE_ONEDNN_OPTS=0` before TF import; enable TF1 compatibility before constructing objects. Numerical equality remains a measured result.
- Separate experiment artifacts from all production prediction/run/report caches. No new CLI flags, `CRUX_OAF_NATIVE_PYTHON` wiring, shared-helper refactor, checkpoint conversion, R2 corpus run, separator install, MLflow change, or notebook UI in the immediate scope.
- **Execution host:** GitHub Actions `ubuntu-24.04` Linux x86-64 first; target Colab CPU Linux x86-64 confirms. An Apple-silicon/macOS ARM64 host cannot resolve or benchmark this wheel for parity. Use `uv python install 3.11` and `uv venv --python 3.11`.

## Review focus

1. Wrong platform (macOS ARM64 rather than Linux x86-64): Task 1 locks specifically for `x86_64-manylinux_2_17` and executes graph checks in GitHub Linux.
2. Compatibility patch changes old tensor coverage or preprocessing: Task 2 stdlib patch-scope/layout test protects the frozen copied engine; the real model still performs all original coverage checks.
3. Duplicated exact comparator or event protocol drifts: Task 4 uses existing `WorkerProcess`, `_decode_native_event` and `_event_from_native` with the retained oracle tests.
4. Python 3.11 test leaks into bare IDM pytest or Python 3.12 root tests: builder tests in `tests/runtime` are **stdlib only**, driver tests in `tests/benchmark` use root dependencies, TF graph checks run only in the separate job.
5. A partial/skipped run is mistaken for parity: Task 4 uses nullable inference/repeatability/oracle fields and derives one label; Task 5 records CI/Colab execution separately.
